# 🧠 AI Mental Health Chatbot

This project is an AI-powered chatbot designed to provide emotional and mental health support using a Large Language Model (LLM).

## 🌟 Features
- AI-based conversation
- Provides supportive and empathetic responses
- Simple and user-friendly chat interface

## 🛠️ Tech Stack
- Python (Gradio)
- OpenRouter API (LLM)
- Hugging Face Spaces (Deployment)
